# as2910.github.io

Personal site for Ashish Sinha. PM at Pepper Content. Author of Weekly AI Digest.

Single-page static site. No build step. Vanilla HTML, CSS, and JavaScript.

## Files

- `index.html`. Markup and copy.
- `css/styles.css`. Styles.
- `js/scripts.js`. Sticky header state, scroll spy, reveal-on-scroll.
- `favicon.ico`.

## Local preview

Open `index.html` in a browser, or serve the directory:

```
python3 -m http.server 8000
```

## Deploy

Hosted via GitHub Pages.
